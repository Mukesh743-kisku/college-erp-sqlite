# 🎓 College ERP SQLite

A **Student ERP System for Marwari College** built using **Streamlit** and **SQLite**. 
This project helps manage student data, attendance, and records directly in the browser.

## 📌 Features

- 👨‍🎓 Student Registration & Management
- 📊 Attendance Tracking System
- 📝 Marks/Grade Management
- 🔍 Search & Filter Student Records
- 🔐 Admin Login for Data Security
- 📥 Export Data to Excel/CSV
- 🎨 Simple & Clean Streamlit UI
- ⚡ Lightweight SQLite Database - No Server Needed

---

## 🛠️ Tech Stack

- **Frontend:** Streamlit
- **Backend:** Python
- **Database:** SQLite
- **Hosting:** Render / Streamlit Cloud
